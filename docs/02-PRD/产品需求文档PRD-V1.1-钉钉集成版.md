# 运维AI故障知识库平台

> 产品代号：AI-OpsAI-IT（OpsAI-IT 故障问答知识库）  
> 文档版本：V1.1  
> 文档状态：需求评审稿  
> 产品阶段：第一期——知识库核心能力  
> 运行载体：响应式 Web + 钉钉企业内部 H5 微应用  
> 编制日期：2026-07-30

## 1. 项目概述

### 1.1 项目背景

公司内部常见 IT 故障被重复咨询，知识分散在个人经验、聊天记录和临时文档中，员工难以快速找到可信答案。现有处理方式还存在步骤口径不一致、知识过期、移动端使用不便、内部 SOP 可见范围不清晰等问题。

钉钉已是员工日常办公入口。项目将知识库注册为企业内部 H5 微应用，由钉钉提供工作台入口、组织身份和消息通道；知识内容、搜索、权限、审核、统计及后续扩展能力仍由独立部署的知识库平台负责。

### 1.2 建设目标

- 员工可从钉钉工作台一键进入，正常情况下无需再次输入账号密码。
- 通过搜索、分类和标签快速获得经过审核的故障答案与操作指南。
- 建立知识创建、审核、发布、复审、下架和版本追踪的完整生命周期。
- 同时支持 PC 与移动端阅读、反馈和 IT 服务跳转。
- 建立服务端 RBAC 和数据可见范围控制，为 AI 问答与 ITSM 集成预留扩展能力。

### 1.3 项目价值

- **员工价值**：减少查找入口和重复描述问题的时间，提高自助排障效率。
- **运维价值**：降低重复咨询量，将个人经验沉淀为可维护的组织知识。
- **管理价值**：通过审核、版本、有效期和审计机制降低操作及信息泄露风险。
- **数据价值**：通过搜索、反馈、零结果和服务跳转数据持续识别知识缺口。

### 1.4 V1.1 范围边界

V1.1 聚焦“知识库 + 钉钉基础集成”，包括钉钉入口与免登、搜索、知识生命周期、权限、通知、运营统计及现有 IT 服务入口跳转。

完整大模型多轮问答、完整 ITSM 工单生命周期、资产全生命周期管理、自动权限治理、复杂 BI、知识图谱及外部门户不在 V1.1 范围内。

### 1.5 建议成功指标

| 指标 | V1.1 建议目标 | 统计周期 |
| --- | ---: | --- |
| 钉钉免登成功率 | ≥ 99% | 日 / 周 |
| 搜索成功率 | ≥ 70% | 周 / 月 |
| 自助解决率 | ≥ 50%，上线后持续提升 | 月 |
| 零结果率 | ≤ 15% | 周 / 月 |
| 已发布知识有效率 | ≥ 95% | 月 |
| 移动端 P0 场景可用率 | 100% | 版本 |
| IT 服务入口跳转完成率 | ≥ 98% | 周 / 月 |

## 2. 用户角色

### 2.1 普通员工

- 搜索、分类浏览和阅读本人有权查看的知识。
- 收藏知识并提交“已解决 / 未解决”等反馈。
- 知识未解决问题时，跳转到现有 IT 服务申请入口。

### 2.2 IT运维人员

- 作为知识编辑员创建、维护和提交故障处理知识。
- 作为审核员校验内容的准确性、安全性、适用范围和表达质量。
- 根据零结果、负向反馈和服务跳转数据补充或优化知识。

### 2.3 管理人员

- 维护知识空间、分类、标签、模板、负责人和复审规则。
- 审核或授权发布、下架及归档内容。
- 查看知识质量、使用情况、自助解决率和服务跳转等运营指标。

### 2.4 系统管理员

- 维护钉钉应用、凭证、回调、用户同步和环境配置。
- 管理平台角色、账号状态及集成日志，处理免登、通知和同步故障。
- 负责部署、监控、备份恢复、容量和安全策略。
- 系统集成管理权与知识内容审批权默认分离。

## 3. 产品需求

### 3.1 知识库管理

- 支持按模板创建知识，并管理草稿、预览、审核、发布、复审、下架和归档。
- 记录版本号、修改人、修改时间、修改说明和审核结论。
- 维护知识空间、业务分类、文章类型、标签、适用范围、负责人和有效期。
- 已下架或已归档内容不得出现在员工搜索结果中。

### 3.2 AI智能问答

- **V1.1 当前能力**：以全文搜索、搜索联想、同义词、相关性排序、分类筛选和相关知识推荐实现智能检索。
- **结果可信要求**：只检索当前用户有权限访问且处于有效发布状态的知识。
- **V2.0 规划能力**：基于已审核知识构建检索增强问答，支持答案引用来源、会话反馈和安全控制。
- V2.0 上线前，不将搜索结果包装成无来源的生成式答案。

### 3.3 故障知识沉淀

- 统一描述问题现象、适用范围、处理步骤、风险提示、验证方法及相关资料。
- 员工可反馈“已解决 / 未解决”“内容错误”“内容过期”或“看不懂”。
- 未解决时保留搜索词、知识编号、问题分类和终端等上下文，并在目标表单支持时预填。
- 运营人员根据零结果、高频搜索、负向反馈和服务跳转数据建立知识补充清单。

### 3.4 权限管理

- 钉钉应用范围决定用户是否能打开入口，平台 RBAC 决定进入后能看什么、能做什么。
- 支持全员、指定部门、指定角色、仅 IT、仅管理员等内容可见范围。
- 用户可拥有多个角色，权限取并集；账号显式禁用优先。
- 搜索、详情、附件下载和后台接口均须执行服务端权限校验。

### 3.5 数据统计

- 统计访问人数、免登成功率、PC / 移动端占比和活跃部门。
- 统计搜索次数、零结果词、低点击词、搜索后服务跳转及响应时间。
- 统计知识访问量、正向反馈率、未解决原因、即将到期和过期知识。
- 统计新增、审核、发布、驳回、平均审核时长和负责人逾期情况。
- 运营数据用于改善知识覆盖和体验，默认不用于员工绩效考核。

## 4. 功能详细说明

### 4.1 钉钉入口与身份认证

- **功能描述**：提供企业内部 H5 微应用入口，使用短期免登授权码换取可信员工身份并建立平台会话。
- **用户场景**：员工从钉钉 PC 或移动工作台进入“IT 知识库”。
- **输入**：免登授权码、企业标识、防重放参数和终端信息。
- **输出**：平台会话、用户信息、角色与可见范围；失败时输出错误码、重试入口和 IT 联系方式。
- **业务规则**：后端按 `corpId + dingUserId / unionId` 映射用户；同时校验组织身份、应用范围和平台账号状态；不得信任前端传入的姓名、部门或角色作为授权依据。

### 4.2 首页、导航与知识发现

- **功能描述**：提供搜索框、高频分类、热门知识、常用专题、公告和个人内容入口。
- **用户场景**：员工搜索“打印机离线”，或从网络、账号、软件、设备等分类浏览方案。
- **输入**：搜索词、分类、文章类型、适用系统、更新时间及终端类型。
- **输出**：高亮后的搜索结果、筛选项、相关知识；零结果时提供推荐词、热门分类和 IT 服务入口。
- **业务规则**：全文检索标题、摘要、正文、标签、分类和同义词；排序综合相关性、发布时间、点击量、反馈和有效性；索引不得泄露无权内容。

### 4.3 知识详情与反馈

- **功能描述**：结构化展示知识内容，并收集知识是否解决问题的反馈。
- **用户场景**：员工按步骤排障、查看截图、验证结果，并选择“已解决”或“未解决”。
- **输入**：知识编号、用户权限、反馈结果、可选原因和终端信息。
- **输出**：标题、摘要、适用范围、步骤、截图、风险提示、验证方法、版本信息、相关知识和服务入口。
- **业务规则**：过期、下架或无权限内容不得正常展示；附件继承文章权限；移动端图片不得横向溢出；风险操作先展示影响范围或备份提示。

### 4.4 知识创建、审核与版本管理

- **功能描述**：建立知识从创建到归档的受控生命周期。
- **用户场景**：IT 运维人员按模板编写知识，审核员审批后发布，负责人到期复审。
- **输入**：模板、标题、摘要、正文、适用范围、负责人、复审日期、可见范围、版本说明和附件。
- **输出**：草稿、待审核版本、审核结果、已发布版本、历史版本及钉钉通知。
- **业务规则**：提交时冻结待审版本；审核员可通过或驳回；发布内容修改时创建新版本，旧版本在新版本通过前继续有效；紧急下架必须填写原因并保留审计记录。

### 4.5 故障服务闭环

- **功能描述**：当知识无法解决问题时，连接现有钉钉多维表或 OA 审批入口。
- **用户场景**：员工在文章详情或零结果页点击“提交 IT 服务申请”。
- **输入**：来源页面、搜索词、知识编号、问题分类、终端信息和用户反馈。
- **输出**：打开现有服务表单；失败时提供备用入口、二维码或复制链接。
- **业务规则**：V1.1 不在知识库内创建完整工单；目标能力允许时才预填上下文；记录跳转结果和失败原因，不记录非必要敏感内容。

### 4.6 权限与可见范围

- **功能描述**：通过角色和数据范围控制知识访问及管理操作。
- **用户场景**：员工查看本人可见知识，IT 人员查看授权 SOP，管理员执行配置操作。
- **输入**：用户身份、角色、部门、知识空间、文章范围和账号状态。
- **输出**：允许访问的内容和操作，或不泄露知识标题、摘要及附件信息的拒绝结果。
- **业务规则**：权限判断在服务端完成；显式禁用优先；角色授权、撤销、范围变更、发布、下架和导出均需审计。

### 4.7 通知与待办

- **功能描述**：通过钉钉工作通知传递审核、驳回、复审和重要公告。
- **用户场景**：审核员收到待审提醒并直达审核页，作者收到审批结果，负责人收到到期提醒。
- **输入**：业务事件、接收范围、消息模板、目标页面和幂等键。
- **输出**：钉钉通知、发送状态、重试记录和失败告警。
- **业务规则**：同一事件不得重复发送；失败可重试；非强制通知支持频控、汇总或退订；通知不得包含密码、密钥或服务器敏感配置。

### 4.8 管理后台与数据统计

- **功能描述**：管理基础配置、用户角色、内容运营、集成日志和运营看板。
- **用户场景**：管理员查看待审、即将到期和负向反馈知识，定位免登失败，导出脱敏数据。
- **输入**：配置项、查询条件、时间范围、用户权限和导出范围。
- **输出**：配置结果、内容队列、统计指标、日志检索结果和受控导出文件。
- **业务规则**：导出遵循最小权限并记录审计；敏感字段脱敏；统计口径稳定；后台任务异步执行。

### 4.9 知识状态与流转

知识状态包括：草稿、待审核、已发布、已过期、已下架和已归档。

- 草稿提交后进入待审核；审核驳回则回到草稿。
- 审核通过后发布，旧发布版本保留为历史记录。
- 超过复审日期后按风险等级和管理策略标记或限制展示。
- 管理员或授权审核员可下架知识，但必须填写原因。
- 已归档内容仅供授权管理人员审计和追溯。

## 5. 非功能需求

### 5.1 性能

- 公司常用网络下，首页首屏 P95 不超过 3 秒。
- 正常负载下，搜索响应和文章正文加载 P95 不超过 2 秒。
- 大图采用压缩、缩略图和懒加载。
- 容量测试以预计员工数和峰值并发为基准，至少保留 50% 余量。
- 用户同步、索引和通知采用异步任务，不阻塞阅读流程。

### 5.2 安全

- 正式环境使用 HTTPS，内部接口运行在受控网络并执行鉴权。
- 钉钉凭证集中保存、分环境管理、定期轮换，禁止写入前端、代码仓库和普通日志。
- 搜索、详情、附件和后台接口执行服务端 RBAC 与数据范围校验。
- 记录登录、授权、发布、下架、配置、导出及集成管理操作。
- 对令牌、授权码、手机号、邮箱、IP 和敏感搜索词执行脱敏与访问控制。
- 建议月度可用性不低于 99.5%；数据库每日备份，建议 RPO ≤ 24 小时、RTO ≤ 4 小时，最终指标由运维与架构确认。

### 5.3 可扩展性

- 知识、搜索、认证、通知、统计和 ITSM 集成保持清晰模块边界。
- 钉钉能力通过适配层封装，业务代码不直接依赖具体接口细节。
- 文章采用可迁移的结构化格式，保留版本、段落、引用来源、可见范围和有效性字段。
- 为 AI 检索增强问答及 ITSM 状态回写预留标准接口和上下文字段。

### 5.4 易用性

- 支持主流 Windows 10 / 11、iOS 和 Android 上的钉钉客户端。
- PC 与移动端采用响应式布局，手机端不得出现横向溢出、遮挡或不可点击。
- 错误信息说明问题、可执行动作和求助方式。
- 操作步骤以动词开头，重要截图配文字说明，颜色不得作为唯一信息载体。
- 按钮使用结果导向文案，例如“提交审核”“打开 IT 服务申请”。
